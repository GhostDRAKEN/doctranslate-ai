# Roadmap

## Version MVP

Objectif : prototype demonstrable pour PDF numeriques propres.

Fonctionnalites :

- upload PDF ;
- extraction texte et blocs simples ;
- traduction anglais vers francais ;
- glossaire simple ;
- generation DOCX ;
- rapport de validation ;
- interface web claire.

## Version avancee

Objectif : ameliorer la robustesse documentaire.

Fonctionnalites :

- meilleure detection multi-colonnes ;
- extraction tableaux plus fiable ;
- export PDF stable ;
- comparaison visuelle simple source/resultat ;
- edition manuelle du glossaire avant traduction ;
- preview du document traduit.

## Version professionnelle

Objectif : usage reel en contexte metier.

Fonctionnalites :

- authentification ;
- gestion utilisateurs et roles ;
- historique persistant ;
- stockage cloud chiffre ;
- memoire de traduction ;
- glossaires par organisation ;
- traitement par lots ;
- files de jobs avec workers.

## Version SaaS

Objectif : produit commercialisable.

Fonctionnalites :

- abonnements et paiement ;
- quotas ;
- API publique ;
- monitoring ;
- audit logs ;
- suppression automatique configurable ;
- options de confidentialite avancees ;
- tableau de bord admin.

## Fonctionnalites futures

### OCR

- detection automatique de pages scannees ;
- OCR avec Tesseract, PaddleOCR ou service cloud ;
- controle de qualite OCR ;
- reconstruction depuis texte OCR.

### Documents scannes complexes

- segmentation avancee ;
- detection de colonnes ;
- correction d'inclinaison ;
- traitement des images basse qualite.

### Comparaison visuelle

- rendu source/resultat ;
- detection de debordements ;
- score de similarite layout ;
- apercu cote a cote.

### Memoire de traduction

- stockage de segments source/cible ;
- reutilisation automatique ;
- suggestions de traduction ;
- coherence multi-documents.

### API publique

- endpoints securises ;
- cles API ;
- webhooks ;
- documentation OpenAPI publique ;
- limites de debit.
